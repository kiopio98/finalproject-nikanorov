# Проверка проекта

Проверено на Python 3.12.14 и uv 0.13.6 под Windows.

| Проверка | Результат |
| --- | --- |
| `uv sync --locked` в чистой копии репозитория | успешно |
| `uv run project`, завершение через `exit` | успешно |
| `uv run ruff check .` | All checks passed |
| `uv run python -m unittest discover -s tests -v` | 26 тестов, OK |
| `uv build` из исходников и из чистой копии | sdist и wheel собраны |
| Установка wheel в отдельное окружение | успешно |
| Запуск установленной команды вне каталога исходников | успешно |
| Регистрация → вход → покупка → продажа → портфель из wheel | успешно |
| Код завершения при ошибке одиночной команды | 1 |
| Настоящий запрос CoinGecko | получены три корректные пары |
| Настоящий запрос ExchangeRate-API Open Access | получены три корректные пары |
| Воспроизводимая демонстрация с учебными HTTP-ответами | успешно |

Тесты проверяют соли и хеши, восстановление пользователей, валидацию сумм,
недостаток средств, изоляцию портфелей, TTL обеих частей кросс-курса, обновление
просроченного кеша, отказ сделки при недоступном курсе, обработку HTTP-ошибок,
сохранение исправных данных при частичном сбое API, историю и дедупликацию,
атомарную замену JSON, восстановление прерванной записи и файловую блокировку.

В демонстрации показаны все основные команды, обе операции сделки, оценка
портфеля в EUR, обновление/просмотр курсов и несколько ошибок ввода.
Учебные HTTP-ответы явно обозначены в начале записи; реальные цены и
пользовательские данные в репозиторий не включены.
